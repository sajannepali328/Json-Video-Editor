# JSON Video Editor 🎬

A simple Python tool to edit and render videos using a `settings.json` file.

## Features
* Merge and trim video/image clips
* Add text overlays and Ken Burns image effects
* Handle transitions, clip speeds, and audio volume
* Background music mixing and audio normalization

## How to Run

1. Install dependencies:
   ```bash
   pip install pillow

```

*(Make sure FFmpeg is installed on your system)*

2. Put your media in the `media/` folder and update `settings.json`.
3. Run the script:
```bash
python test.py

```
